01

Qué es esta aplicación

Finanzas Personales es una aplicación de uso familiar para llevar el control de ingresos y gastos del hogar. La usan únicamente las personas de la familia que su administrador autoriza explícitamente.

No es un producto comercial, no está disponible al público y no se ofrece a terceros.

02

Qué información se recopila

Solo lo necesario para registrar los movimientos financieros de quien la usa:

  • Número de teléfono de WhatsApp de las personas autorizadas a cargar gastos.
  • El texto de los mensajes que envían para registrar un gasto (monto, categoría, medio de pago, fecha).
  • Los datos que cargan a mano o por el chat web: ingresos, gastos fijos, compras en cuotas, cuentas y tarjetas.
sin ubicación sin contactos sin fotos ni multimedia
03

Cómo se usa esa información

El texto de cada mensaje se envía a la API de Claude (Anthropic) únicamente para interpretar el gasto descrito —monto, categoría y medio de pago— y cargarlo en la base de datos de la aplicación.

No se usa para entrenar modelos de inteligencia artificial, ni con fines publicitarios, ni para elaborar perfiles fuera del control de gastos del hogar.

04

Con quién se comparte

Únicamente con los proveedores técnicos que hacen funcionar la aplicación:

  • Meta / WhatsApp, como canal de mensajería.
  • Anthropic, para interpretar el texto de los mensajes de gasto.
  • Neon, donde se aloja la base de datos privada de la aplicación.

La información financiera no se vende ni se comparte con terceros con fines comerciales o publicitarios.

05

Dónde se guarda y por cuánto tiempo

Los datos se guardan en una base de datos privada con acceso restringido. El detalle de cada movimiento se conserva hasta 24 meses; pasado ese plazo se archiva y se retira del detalle activo.

06

Quién puede acceder

Solo los números de teléfono que el administrador autoriza de forma explícita pueden cargar gastos por WhatsApp. El acceso a la aplicación web está protegido por autenticación.
